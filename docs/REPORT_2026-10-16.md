## 2. 验证方法论

1. **双源门**:冻结夹具(frozen dumps)+ 活体重算(live)双源;
2. **f64 卡尺**:全程 float64 对账,金标准=亚微单位/f64 噪声级;
3. **分段检查点审计(本日新增基建)**:反向链 7 个 stage 边界镜像内部伴随,
   与 python autograd 全模型逐段对账(定位 ⑧ 缺项的武器,全部 1e-8 级通过);

5. **平移不变性**:ΣF 应达 f64 精度(实际 ~1e-14~1e-16)。

## 5. 性能基准(A100-80GB,f64,能量+力 单次 eval,NH3×32/128 原子)

**成本阶梯(核心结论)**:

| 配置 | median | 相对增量 |
|---|---|---|
| 骨干 only(`polaroff`) | **405.6 ms** | —(P2 历史口径 0.4–0.5 s 吻合) |
| + 静电层(SCF+k 空间+⑥;`leoff`) | **5105.4 ms** | **+4.70 s** |
| + local_electron(全模型) | **7206.5 ms** | **+2.10 s** |
| **反向(力)增量** | **≈0 ms** | 能量-only 6951.7 vs +力 6916.1 ms——**力几乎免费** |

**标度行为**(全模型):
| 变量 | 结果 |
|---|---|
| RBE p=50 / 200 / 800 | 6996 / 6963 / 7020 ms ⇒ **与 p 无关**(RBE 不额外加价) |
| 原子数 ×8(128→1024,2×2×2) | 7796 ms(+12%) ⇒ **弱 n 依赖,固定开销主导** |
| k 数(50→800) | 无感(同上) |

要点(诚实口径):
- ~7 s/eval 的成本 = **前向极化管线**(SCF×2 步 + 描述符 + ⑥ + le)的固定型开销,
  与反向链无关(反向增量 ~0);骨干 0.41 s vs 极化层 6.8 s → 极化层 ≈17× 骨干;
- 已知优化方向(P5/性能台阶,按预期收益排序):① 宿主端 GEMM 单线程告警所指的
  宿主 BLAS 路径(OpenMP-enabled OpenBLAS);② 每 eval 的表示重建(compact edges/
  固定工作区);③ JIT(nvrtc)内核;④ 宿主-设备同步消除;
- 基准环境:GPU1 与采样 MD 任务共享(SM ~34%),绝对值偏保守;产物
  `bench/polar_perf.{json,png}` + `logs/perf_breakdown_v28.log`。
