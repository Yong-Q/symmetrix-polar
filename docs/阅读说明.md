# Symmetrix-Polar 速度与精度对比 · 阅读说明

> **最终结果先看：** [results/PLAN_B_30MS_FINAL.md](results/PLAN_B_30MS_FINAL.md)
> —— 128 原子（32 个 NH3 分子）**30.56 ms/eval**（full PolarMACE，FP64；
> 相对 round-3 build 8 1.595×，比 PyTorch 参考快 3.08×），
> 1024 原子（256 个 NH3 分子）**312 ms/eval**；全部数值门 PASS
> （含 2-rank exact parity 和重复评估）；RBE 被生产力精度门拒绝。
> 下面的 2026-10-19 对比报告是 round-2 的历史版本。

本阅读包汇总 MACE-Polar（PolarMACE）在 Symmetrix-XL 非线性引擎中的速度、能量/力精度、
MPI 行为与已否决路径。所有数字来自仓库内的 JSON/日志，不重新估算；仍在校准中的优化
结果明确标记为“in flight / pending”。

**Plan B-lite（2026-10-20，最新 gated）**：128 原子 full PolarMACE
**40.95 ms/eval**，相对 round-3 build 8（48.74）**1.190×**，相对 v29
（183.8）**4.49×**，比 PyTorch 参考 94.0 ms 快 **2.30×**；polar-off
**19.93 ms**。两个有效切片：B1 replay cache **+3.39 ms**、B4 reverse-gather
fusion **+4.01 ms**；B3 merged unpack 数值正确但慢 5.97 ms（保持 opt-in）。
全部数值门 PASS（module 5–8、32/32、LAMMPS 1-rank/2-rank exact parity）。
离 30 ms 还差 ~10.95 ms，当前在攻 host-gap/launch elimination。

**round 2（2026-10-19）历史**：128 原子全模型 **122.2 → 56.5 ms/eval
（2.17×）**，polar-off **40.6 → 27.7 ms（1.47×）**；432 原子 N2
**294.4 → 126.6 ms/step（2.33×）**。相对 v29（183.5 ms）累计 **3.25×**，
相对 v28（6966.8 ms）累计 **123×**。
round 2 的一个关键发现是：之前“已验收”的二进制链接了旧 object，
实际仍在跑 26 ms 的旧 `polar reverse dense` 和未融合的 normalization；
强制重建后这两项单独就省了 ~39 ms。详见
[results/KERNEL_ROUND2.md](results/KERNEL_ROUND2.md)。

## 数据口径

- 硬件：单张 NVIDIA A100-80GB；除 MPI 条目外均为 1 rank；f64。
- 能量单位 eV，力 eV/Å，时间 ms/eval 或 ms/step。
- 生产长度按 PNAS 口径：NVT + Nosé–Hoover，0.5 fs，1 ns = 2,000,000 步。
- “同模型”指 PolarMACE（`polar_symmetrix_probe.json`）。MACE-OFF23 medium
  是**不同模型**（37 MB、10 元素、r_cut 5 Å），只作线性引擎参照。
- **gate 是最低标准**：RBE（p=50/200/800）与 1-hop ghost MPI 均未通过力门，
  因此不作为生产替代；只保留精确全 k 与 exact 2-hop/正确的 H1 路径。
- **MPI H1 现状**：1-rank 缺陷已修复。1-rank 图折叠到 local atoms，
  H1 1-rank **418.64 → 50.20 ms**，默认路径 50.84 ms（**0.99×**）；
  同二进制 A/B 176.77 → 54.62 ms（**3.24×**）；parity dE=0、
  max dF 1.41e-15 eV/Å，20-step NVT 稳定。**2-rank 被引擎侧 workspace
  分配阻塞**：每个 rank 6 个 2.0–5.4 GiB workspace（合计 ~21 GiB/rank，
  峰值 80,966 MiB），exact 2-hop OOM、H1 SIGSEGV；已启动专门的
  workspace 修复。修复并通过 2-rank parity 前不报 2-rank 速度。
  详见 [results/MPI_H1.md](results/MPI_H1.md)。
- 仍在进行的优化：round 2 之后的 **MH-1 tensor product 通道分块/寄存器累加/
  zero-fill 删除**（round-3 规划已证明 DMMA 不适用：每输出只有 1–21 个非零项，
  实测 0.12–0.25 TFLOP/s，低于 DMMA ridge 5–12×）、cuBLAS 批处理、
  UVU/affine/cutoff 加宽，以及 Stage 2 的 gather/SCF/host-gap 优化；
  MPI H1 修复与 2/4 卡 scaling。这些结果在报告中标记 pending，
  不写未经验证的数字。
