# Symmetrix-Polar 速度与精度对比 · 阅读说明

打开 [对比报告](COMPARISON_REPORT_2026-10-19.md)、[离线阅读页](index.html)，或直接查看
[figures/](figures/) 与 [examples/](examples/)。

本阅读包汇总 MACE-Polar（PolarMACE）在 Symmetrix-XL 非线性引擎中的速度、能量/力精度、
MPI 行为与已否决路径。所有数字来自仓库内的 JSON/日志，不重新估算；仍在校准中的优化
结果明确标记为“in flight / pending”。

## 阅读顺序

1. **先看成本结构**：`figures/01_cost_structure.png`。128 原子和 432 原子下，
   非线性骨干、长程 k 空间、polar SCF/UVU/LE/反向各占多少。
2. **再看为什么不用 RBE**：`figures/02_rbe_tradeoff.png`。RBE p=50/200/800 更快，
   但力误差都高于 1e-4 eV/Å 的硬门。
3. **精度门**：`figures/03_gate_margins.png`。模块⑤–⑧、端到端、LAMMPS 单点全部
   以很大裕度通过。
4. **MPI 现状**：`figures/06_mpi_status.png`。2-rank exact 正确，但单卡共享不提速；
   1-hop 近似被力门否决。
5. **单点/ MD 证据**：`figures/07_lammps_parity.png`、`figures/08_nvt_md.png`。
6. **生产时间**：`figures/04_homog_cost.png`。216 分子均相盒子的 ms/step 与
   10 ps / 100 ps / 1 ns 外推。
7. **线性 vs 非线性**：`figures/05_engine_compare.png`。注意线性 MACE-OFF23
   不是同一个势，只用于引擎开销参照。

## 数据口径

- 硬件：单张 NVIDIA A100-80GB；除 MPI 条目外均为 1 rank；f64。
- 能量单位 eV，力 eV/Å，时间 ms/eval 或 ms/step。
- 生产长度按 PNAS 口径：NVT + Nosé–Hoover，0.5 fs，1 ns = 2,000,000 步。
- “同模型”指 PolarMACE（`polar_symmetrix_probe.json`）。MACE-OFF23 medium
  是**不同模型**（37 MB、10 元素、r_cut 5 Å），只作线性引擎参照。
- **gate 是最低标准**：RBE（p=50/200/800）与 1-hop ghost MPI 均未通过力门，
  因此不作为生产替代；只保留精确全 k 与 exact 2-hop/正确的 H1 路径。
- 仍在进行的优化：polar 内核、backbone 内核、ncu hot-kernel profile、MPI H1。
  这些结果在报告中标记 pending，不写未经验证的数字。

## 复算入口

`examples/data/` 保存报告引用的 JSON（v28/v29 perf、engine compare、MPI、RBE、
LAMMPS parity、NVT MD、homog timing）。`examples/计算参考/` 保存方法快照：

- `make_comparison_figures.py.txt` — 生成本阅读包的 01–04 图；
- `make_polar_figures.py.txt` — 生成 05/06 等图；
- `polar_lammps_parity.py.txt` — 单点 parity 门；
- `polar_lammps_md.py.txt` — NVT MD 门；
- `polar_vs_linear_speed.py.txt` — 线性/非线性/完整模型对比；
- `linear_mpi_speed.py.txt` — 上游线性 H1 MPI 对照。

复算时请使用对应的 LAMMPS/Symmetrix 构建与 GPU 环境；完整命令见
[对比报告](COMPARISON_REPORT_2026-10-19.md) 的“复现”一节。
