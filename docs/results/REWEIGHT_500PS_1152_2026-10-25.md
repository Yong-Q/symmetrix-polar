# 500 ps OFF → POLAR reweighting at 1152 atoms (2026-10-25)

**Question:** does a 500 ps MACE-OFF trajectory at production size rescue direct
importance-sampling reweighting to MACE-POLAR, and does it improve the
structure relative to the raw OFF ensemble?

**Answer: no. It is worse than the 96-atom case, not better.** ESS is 2.35 out
of 501 frames (0.47 %), which is a collapse, and the reweighted O–O RDF is
noisier than the unweighted one without moving toward a different structure.

## 1. Input

| item | value |
|---|---|
| trajectory | `bench/off23_500ps_water1152_2026-10-23/traj_500ps_1fs.lammpstrj` |
| system | 1152 atoms (384 H₂O), 23.392 × 23.392 × 35.088 Å |
| source | MACE-OFF23-medium, Symmetrix LAMMPS engine, FP32 linear path |
| protocol | 20 ps NVT equilibration at 1 fs, then 500,000 steps = 500 ps |
| dump | every 1,000 steps = 1 ps → 501 frames |
| wall time | 19:54:04 |
| state point | 300 K nominal (NVT, friction 0.1 ps⁻¹) |

## 2. Reweighting diagnostics

All 501 frames re-evaluated in PyTorch with MACE-OFF23-medium (FP32) and
MACE-POLAR-1-M (FP64). Per-frame total energies, ΔE = E_POLAR − E_OFF.

| quantity | 96 atoms (36 frames) | **1152 atoms (501 frames)** |
|---|---:|---:|
| ΔE/atom mean (constant offset) | 416.62 meV/atom | **417.42 meV/atom** |
| ΔE/atom std | 1.166 meV/atom | **0.309 meV/atom** |
| σ_β (full) | 3.89 | **13.76** |
| ESS | 3.63 / 36 (10.1 %) | **2.35 / 501 (0.47 %)** |
| verdict | marginal | **collapse** |
| slope / intercept | 0.9452 / −3606.84 eV | 0.9248 / −59650.78 eV |
| R² | 0.9866 | 0.9624 |
| residual std | 1.03 meV/atom | 0.286 meV/atom |

The *per-atom* fluctuation shrinks with system size (1.17 → 0.31 meV/atom,
consistent with averaging over more local environments), but σ_β is an
extensive quantity and it **grows** by 3.5×, exactly as σ_β ∝ √N predicts
(√12 = 3.46). The prediction in
`docs/design/OFF_TO_POLAR_REWEIGHTING_2026-10-23.md` was σ_β ≈ 14 at 1296
atoms; the measured value at 1152 atoms is 13.76.

Only **2.35 effective frames** survive out of 501. That is not a sampling
problem that more frames can fix: adding frames to a fixed-width weight
distribution saturates ESS at 1/Σw̃², it does not widen the overlap.

## 3. Structure

The reweighted O–O RDF is added noise on top of the OFF RDF, not a shift
toward a POLAR-like structure. See
`scripts/figures/OFF_TO_POLAR_500PS_1152.png`, bottom-right panel.

This is the expected consequence of the weight collapse: a 2.35-frame
effective sample cannot define a radial distribution function at 80 bins over
2.2–8.0 Å.

## 4. What the linear fit does and does not do

R² = 0.962 looks respectable, and the residual (0.286 meV/atom) is now
*smaller* than the total ΔE fluctuation. But it does not help, for two
reasons:

1. The linear form is applied to the **total** energy, and the residual is
   correlated across frames. The residual-driven weight
   exp(−β·δV) still has σ_β = 13.76 — identical to the full σ_β, because the
   linear part is a near-constant after normalization (the c₂ offset cancels
   and c₁ only rescales the effective temperature).
2. **The slope is 0.925, not 1.** That means the fit is mostly absorbing a
   systematic per-atom reference-energy difference, not describing a physical
   response. Multiplying the source Hamiltonian by 0.925 is equivalent to
   sampling at T/0.925 = 324 K, which is not the target.

## 5. Conclusion and what to do instead

Direct exponential reweighting of an OFF trajectory to POLAR is **not viable
at production size**, and the 500 ps run confirms it with a much stronger
verdict than the 96-atom feasibility test. The honest options, in order:

1. **Short POLAR trajectories** for structure/thermodynamics at the state
   points that matter. One 100 ps POLAR run at 300 K is worth more than any
   amount of OFF reweighting here.
2. **BAR/MBAR with intermediate λ states** — but this requires actually
   sampling the intermediates, so it is a new campaign, not a post-processing
   trick.
3. **A distilled student trained on POLAR labels** for the long-time
   statistics, which is what Path B / Plan C are for.
4. **Mean-gap / Gaussian correction along a collective variable** remains
   legitimate for free-energy profiles. It does not give ensemble averages and
   is not attempted here.

## 7. Caveat on the trajectory itself

The 500 ps run used FP32 (`symmetrix/mace/float32/kk`), so the *source*
sampling has FP32-level noise. That does not affect the reweighting verdict —
the weight collapse comes from the POLAR/OFF energy gap, measured in FP64 —
but it does mean this trajectory should not be used as an FP64-accurate
reference for energy differences.
