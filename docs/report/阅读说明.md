# Symmetrix-Polar 汇报版 · 阅读说明

打开 [离线阅读网页](index.html) 或 [PDF 阅读／打印版](SYMMETRIX_POLAR_REPORT_2026-10-21.pdf)，连续 Markdown 见 [SYMMETRIX_POLAR_REPORT_2026-10-21.md](SYMMETRIX_POLAR_REPORT_2026-10-21.md)。

## 阅读包内容

- `index.html`：离线网页，含侧边目录、公式、配图和表格；公式已排为 PNG，不依赖 MathJax 或网络。
- `SYMMETRIX_POLAR_REPORT_2026-10-21.pdf`：11 页，23 个书签，目录带页码；蓝／青版式，独立公式段、图注和表格。
- `figures/`：优化阶梯、GPU 时间去向、位置对比三张图。
- `math/`：13 个独立公式的 PNG（420 dpi）。
- `OPTIMIZATION_LEDGER.md`：报告每个数字的 git 来源索引。
- `data/`：A/B、sweep、门禁和 CUPTI summary JSON；`data/README.md` 标注了被外部 GPU 争用污染的轮次。

## 口径

所有速度统一为 **µs/atom**，并注明原子数、精度和执行路径。主体结果是 1,296 原子 H₂O、full PolarMACE、FP64、单张 A100-80GB：**462.6 → 224.1 µs/atom（−51.6%）**。目标 4.5 µs/atom 为线性 MACE FP32 streaming 的参照，当前 full polar 差 49.8×。

## 重新生成

在 `Yong-Q/symmetrix-polar` 仓库中：

```bash
python harness/make_report_figures.py
python harness/make_report_pdf.py
python harness/make_report_html.py
```

PDF 由 Markdown + fpdf2 + 数学排版 PNG 生成；网页由 Markdown + mistune + 同一套公式 PNG 生成。原始 A/B、trace 和日志在 gitignore 的 `bench/` 树中；提交的 summary JSON 保存了报告用到的全部数值。
